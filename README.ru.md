# Массовое обновление PPP-цен App Store в 175+ странах — региональные цены по паритету покупательной способности для подписок и встроенных покупок

![PyPI](https://img.shields.io/pypi/v/appstore-ppp-prices)
![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue)
![License: MIT](https://img.shields.io/badge/license-MIT-green)
![Tests](https://img.shields.io/badge/tests-141%20passing-brightgreen)

**appstore-ppp-prices** — бесплатная утилита с открытым исходным кодом, которая массово обновляет цены на встроенные покупки (IAP) и подписки в App Store сразу в **175+ странах** по **паритету покупательной способности (ППС, PPP)**. Берёт коэффициенты из ВВП на душу населения, при желании подстраивает их через GPT под тип вашего приложения и записывает цены напрямую через **App Store Connect API** — одна команда вместо вечера кликов по территориям.

Ключ API не покидает вашу машину, а любой запуск можно сначала посмотреть в режиме предпросмотра.

> **Другие языки:** [English](README.md) · [Português](README.pt.md) · [Español](README.es.md) · [中文](README.zh.md)

```
uv tool install appstore-ppp-prices
ppp-pricing --app-id 123456789 --iap com.app.weekly --dry-run
```

Типичные задачи: рост выручки App Store на развивающихся рынках (Индия, Бразилия, Индонезия), локализация цен для игр и подписочных приложений, массовое изменение цен без ручного прохода по 175 территориям и переоценка руками ИИ-агента вроде Claude Code.

## Почему автоматические цены Apple теряют деньги

Когда вы задаёте цену для США, App Store Connect сам заполняет остальные 174 витрины — но он их **выравнивает**. Цена конвертируется по текущему курсу с поправкой на местный налог, поэтому подписчик в Индии платит примерно столько же **в долларах**, сколько подписчик в Швейцарии.

Курс валюты — не покупательная способность. Медианная зарплата между территориями App Store различается больше чем в 20 раз, так что выровненная цена одновременно слишком высока для развивающихся рынков, где она душит конверсию, и в нескольких самых богатых странах ниже той, что там охотно заплатили бы.

Цены по ППС ставят каждую территорию относительно того, что там действительно могут себе позволить.

## Что делает утилита

1. Подключается к App Store Connect API по вашему ключу `.p8`
2. Забирает встроенные покупки, подписки и их цены для США
3. Считает целевую цену для каждой страны по ВВП на душу населения
4. *(Опционально)* Просит GPT подстроить коэффициенты под тип приложения — у казуальной игры и у AI-инструмента совершенно разная эластичность спроса
5. Подбирает ближайший ценовой тир Apple для каждой цели
6. Применяет всё разом — или печатает таблицу и ничего не меняет при `--dry-run`

## Удобно для ИИ-агентов

Почти все инструменты региональных цен — это веб-панель или приложение для Mac. Здесь одна команда с однозначными флагами, и агент может провести всю задачу целиком:

- **Нет интерфейса и браузерной автоматизации.** Нечего кликать, нечего скриншотить.
- **`--dry-run` печатает читаемую таблицу** — агент сверит цифры до того, как что-то применится.
- **Никаких интерактивных вопросов.** Каждое решение — флаг.
- **Текстовые ошибки и настоящие коды возврата**, так что неудачный запуск невозможно спутать с удачным.
- **Работает в CI** ровно так же, как на ноутбуке.

На практике задачу можно отдать целиком:

> *«Посмотри цены по ППС для недельной подписки, потом применяй везде кроме России и Беларуси»*

а это просто две команды:

```
ppp-pricing --app-id 123456789 --iap com.app.weekly --dry-run
ppp-pricing --app-id 123456789 --iap com.app.weekly --exclude RUS,BLR
```

## Ключ API не покидает вашу машину

Ключ App Store Connect с правами на цены может изменить то, сколько платят ваши клиенты. Облачные сервисы ценообразования требуют загрузить этот ключ к ним на сервер.

Эта утилита работает локально. Файл `.p8` лежит в вашей папке настроек, JWT подписывается на вашей машине, запросы идут напрямую от вас к Apple. Не нужно заводить аккаунт, между вами и Apple нет посредника, и отзывать потом нечего, кроме самого ключа.

## Пошаговая установка

### Шаг 1: Установить программу

Проще всего через [uv](https://docs.astral.sh/uv/) — свой Python для этого не нужен, uv принесёт собственный:

```
uv tool install appstore-ppp-prices
```

Нет uv? Сначала поставьте его: `curl -LsSf https://astral.sh/uv/install.sh | sh` (macOS, Linux) или `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"` (Windows).

Если Python 3.10+ уже стоит, подойдёт любая из этих команд:

```
pipx install appstore-ppp-prices
pip install appstore-ppp-prices
```

На Mac и привычнее через Homebrew?

```
brew tap duceum/tap
brew trust duceum/tap
brew install duceum/tap/appstore-ppp-prices
```

`brew trust` — это Homebrew 6 спрашивает, согласны ли вы исполнять код формулы из стороннего тапа. Установка займёт несколько минут: Homebrew собирает Python-зависимости из исходников, а три из них с нативными расширениями. `uv` ставит готовые колёса и укладывается в секунды.

Ставятся сразу два имени одной и той же программы: `appstore-ppp-prices` и короткое `ppp-pricing`. Дальше в README используется короткое.

Проверьте:
```
ppp-pricing --version
```

Попробовать вообще без установки: `uvx appstore-ppp-prices --help`

### Шаг 2: Создать API-ключ App Store Connect

1. Откройте https://appstoreconnect.apple.com/access/integrations/api
2. Нажмите **"Generate API Key"** (или «Ключи» → «Создать ключ API»)
3. Имя: любое (например, `ppp-pricing`)
4. Права доступа: **Admin** или **App Manager**
5. Нажмите **"Generate"**
6. **Скопируйте Key ID** (10 символов, например `A1B2C3D4E5`)
7. **Скопируйте Issuer ID** (UUID, виден вверху страницы)
8. **Скачайте .p8 файл** — это приватный ключ. Скачать можно только один раз!

Положите `.p8` файл в папку настроек:
```
mkdir -p ~/.config/ppp-pricing
mv ~/Downloads/AuthKey_*.p8 ~/.config/ppp-pricing/
```

### Шаг 3: (Опционально) Получить OpenAI API Key

AI-анализ подстраивает коэффициенты под конкретный тип приложения. Без него используются коэффициенты по ВВП — они вполне рабочие.

1. Откройте https://platform.openai.com/api-keys
2. Создайте ключ и скопируйте его (начинается с `sk-`)

<details>
<summary>Другой провайдер вместо OpenAI</summary>

Запрос — это обычный chat completion в формате OpenAI, поэтому подойдёт всё, что
понимает этот формат: OpenRouter, Groq, Together, Fireworks, DeepSeek или локальные
Ollama, LM Studio, vLLM. Переключается двумя переменными в `.env`:

```
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_MODEL=meta-llama/llama-3.3-70b-instruct
```

`LLM_API_KEY` (или `OPENAI_API_KEY`) тогда содержит ключ этого провайдера. Локальной модели ключ не нужен
вовсе, но переменную всё равно надо чем-то заполнить. `LLM_REQUEST_TIMEOUT`
(в секундах, по умолчанию 120) пригодится для медленных локальных моделей.

</details>

### Шаг 4: Создать файл настроек .env

Создайте файл `.env` рядом с ключом, по пути `~/.config/ppp-pricing/.env` (точка в начале имени обязательна):

```
nano ~/.config/ppp-pricing/.env
```

Заполните своими значениями:
```
ASC_KEY_ID=ваш_key_id
ASC_ISSUER_ID=ваш_issuer_id
ASC_PRIVATE_KEY_PATH=AuthKey_XXXX.p8
LLM_API_KEY=sk-ваш-ключ
```

Замените значения на свои. `ASC_PRIVATE_KEY_PATH` — имя скачанного `.p8` файла; если указано просто имя, файл ищется рядом с `.env`.

Хотите держать настройки в другом месте? Укажите его через `--config /путь/к/папке`, задайте переменную `PPP_PRICING_CONFIG` или просто запускайте программу из папки, где лежит `.env`.

### Шаг 5: Проверить установку

Запустите команду со своим App ID (9-значное число из App Store Connect):
```
ppp-pricing --app-id 123456789
```

Если всё настроено верно, увидите список всех IAP и подписок вашего приложения.

## Использование

### Показать все продукты
```
ppp-pricing --app-id 123456789
```

### Предпросмотр цен (без применения)
```
ppp-pricing --app-id 123456789 --iap com.app.weekly --dry-run
```

Покажет таблицу рассчитанных цен по странам. В App Store ничего не меняется.

### Применить цены
```
ppp-pricing --app-id 123456789 --iap com.app.weekly
```

**Внимание**: эта команда реально изменит цены в App Store Connect!

### Опции

| Опция | Описание |
|-------|----------|
| `--dry-run` | Предпросмотр без применения |
| `--no-ai` | Отключить AI-анализ |
| `--us-price 5.99` | Переопределить цену для США |
| `--coeff emerging=0.70` | Задать коэффициент для категории вручную |
| `--exclude RUS,BLR` | Исключить страны (через запятую) |
| `--preserved` | Сохранить текущую цену для действующих подписчиков (только подписки) |
| `--start-date 2026-08-01` | Дата вступления новых цен в силу (только подписки; по умолчанию через 2 дня) |
| `--config ~/keys/` | Указать папку с .env и .p8 файлом |
| `--clear-cache` | Удалить кэш AI-анализа и выйти |
| `--version` | Показать версию |

### Примеры

Предпросмотр с AI-анализом:
```
ppp-pricing --app-id 123456789 --iap com.app.weekly --dry-run
```

Предпросмотр без AI:
```
ppp-pricing --app-id 123456789 --iap com.app.weekly --dry-run --no-ai
```

Применить цены, исключив Россию и Беларусь:
```
ppp-pricing --app-id 123456789 --iap com.app.weekly --exclude RUS,BLR
```

Переопределить коэффициент для развивающихся рынков:
```
ppp-pricing --app-id 123456789 --iap com.app.weekly --coeff emerging=0.50 --dry-run
```

Поднять цену только для новых подписчиков со следующего месяца:
```
ppp-pricing --app-id 123456789 --iap com.app.weekly --preserved --start-date 2026-09-01
```

Очистить кэш AI-анализа:
```
ppp-pricing --clear-cache
```

## Частые вопросы

**Изменится ли цена для действующих подписчиков?**
По умолчанию да — изменение цены касается всех. Флаг `--preserved` оставляет текущим подписчикам старую цену, а новую применяет только к новым. Работает только для подписок: у разовых встроенных покупок такого понятия нет.

**Можно посмотреть, что произойдёт, до применения?**
Для этого и нужен `--dry-run`. Он печатает полную таблицу из 174 целевых цен и ничего не записывает.

**Работает и со встроенными покупками, и с подписками?**
С обоими. У них разные эндпоинты App Store Connect, утилита сама выбирает нужный.

**Куда уходит мой ключ App Store Connect API?**
Никуда. Он остаётся в вашей папке настроек, JWT подписывается локально, запросы идут напрямую к Apple.

**Как считаются коэффициенты?**
Каждая страна попадает в одну из шести групп по ВВП на душу населения, у каждой группы свой множитель относительно цены для США. С ключом OpenAI GPT подстраивает эти множители под категорию приложения и эластичность спроса: казуальная игра выдерживает куда более глубокие скидки, чем AI-инструмент, у которого каждый запрос стоит денег на сервере. Минимальный коэффициент — 0.35, действуют нижние границы $0.99 и $0.49, а пропорции между вашими продуктами сохраняются.

**Можно запускать из CI или из ИИ-агента?**
Да. Никаких интерактивных вопросов, однозначные флаги, настоящие коды возврата. См. [Удобно для ИИ-агентов](#удобно-для-ии-агентов).

**Google Play поддерживается?**
Пока нет, только App Store.

**Можно запланировать изменение цены?**
Да, для подписок: `--start-date YYYY-MM-DD`. По умолчанию — через два дня.

**Что если я не согласен с группой для конкретной страны?**
Переопределите категорию целиком через `--coeff emerging=0.50`, исключите страны через `--exclude` или отредактируйте `countries.csv`.

## Решение проблем

| Проблема | Решение |
|----------|---------|
| `Error: Missing App Store Connect credentials` | Проверьте `.env` — должны быть заданы все 3 переменные (ASC_KEY_ID, ASC_ISSUER_ID, ASC_PRIVATE_KEY_PATH) |
| `Error: Private key not found` | Проверьте, что `.p8` лежит рядом с `.env` и имя в `.env` совпадает |
| `Error: Could not fetch US price` | Убедитесь, что у продукта задана цена для США в App Store Connect |
| `command not found: appstore-ppp-prices` | Переустановите: `uv tool install appstore-ppp-prices`, либо откройте новый терминал, чтобы подхватился `PATH` |
| `Error: No USD price points available` | У продукта нет доступных ценовых тиров. Проверьте настройки в App Store Connect |
